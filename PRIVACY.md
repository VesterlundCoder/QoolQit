# Privacy Policy

## Telemetry

**Telemetry is OFF by default.** This repository does not collect, transmit,
or store any usage data.

## What this repository does

- Runs quantum emulation locally using QoolQit and Pulser.
- Writes results to the local filesystem under `results/`.
- Generates notebooks and slides locally.
- Does not make network requests during benchmark execution.

## What this repository does not do

- Does not phone home.
- Does not report usage statistics.
- Does not require an account.
- Does not upload data to any server.

## If you choose to share results

If you share benchmark results (e.g., via a GitHub issue), you are
responsible for ensuring no sensitive information is included. The raw
result files contain only mathematical problem data and emulation metrics.
